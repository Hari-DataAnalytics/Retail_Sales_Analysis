# 📊 Retail Sales Analysis Dashboard

Transforming raw retail data into actionable business insights using Power BI, Excel, and Power Query.

---

## 🚀 Project Overview

The **Retail Sales Analysis Dashboard** was developed to analyze and visualize retail business performance across different retailers and product categories. This project focuses on converting raw sales data into meaningful insights through interactive dashboards, KPI tracking, and data-driven reporting.

The dashboard enables users to monitor sales trends, compare retailer performance, identify profitable product categories, and support better business decision-making.
